# Перенос и совместимость данных

## Полная резервная копия

В разделе «Данные» можно скачать ZIP и восстановить его на этом или другом компьютере. Формат архива: `tutoring-web-app.backup`, версия `2`; архивы версии `1` также принимаются. В нём есть `manifest.json`, `records.json` и связанные файлы `uploads/`. Манифест содержит версии, число записей и SHA-256 каждого файла. При загрузке приложение проверяет структуру, размеры, пути и контрольные суммы до изменения базы.

В архив входят все прикладные записи: ученики репетиторства, предметы, темы, еженедельные правила и отдельные занятия (включая переносы, отмены и цены состоявшихся), заметки, школьные классы и их ученики, школьные серии и уроки, задачи, классы задач, подборки, позиции подборок, загруженные работы и внесения денег. Токены помощника, API-ключи, Django-сессии и временные файлы в архив не входят. После переноса помощника нужно подключить снова.

Восстановление **заменяет** эти записи и загруженные работы. Перед заменой приложение сохраняет предыдущую полную копию в локальной папке `data/backups/` (либо `$TUTOR_DATA_DIR/backups/`). Если импорт завершится ошибкой, изменение базы отменяется. Сохранённый файл можно загрузить через тот же интерфейс, чтобы вернуться к прежним данным. Для нового устройства сначала установите приложение и выполните миграции, затем загрузите архив.

`records.json` хранит версии моделей с устойчивыми UUID. Для будущих выпусков правило такое: старый архив версии 1 должен продолжать читаться. При изменении поля или связи нужно добавить адаптер чтения старой версии либо новую версию архива с сохранением импорта v1. При выпуске обновления проверять восстановление архивов предыдущих версий на мигрированной базе. SQLite-схема обновляется миграциями Django; нельзя удалять старую миграцию, от которой зависит существующая база. Расписание переносится вместе с правилами повторения и уже созданными экземплярами занятий, поэтому переносы и отмены сохраняются.

## Финансовый JSON

В разделе «Финансы» кнопка «Финансовый JSON» скачивает полный финансовый файл `tutoring-web-app.finances` версии `1`. Его поля:

```json
{
  "format": "tutoring-web-app.finances",
  "version": 1,
  "created_at": "2026-10-27T12:00:00+00:00",
  "students": [{"id": "UUID", "name": "Имя", "price_rub": 1500, "opening_balance_rub": 0}],
  "payments": [{"id": "UUID", "student_id": "UUID", "paid_on": "2026-10-27", "amount_rub": 3000, "note": "Аванс"}],
  "completed_lessons": [{"id": "UUID", "student_id": "UUID", "date": "2026-10-27", "charged_price_rub": 1500}]
}
```

Загрузка показывает, сколько цен, остатков, внесений и начислений изменится. Совпадающие UUID обновляются, новые внесения добавляются; повторная загрузка не создаёт дублей. Из файла не создаются ученики и занятия: их UUID, а для занятия ещё ученик и дата, должны совпадать с текущей базой. При отсутствии записей или конфликте загрузка блокируется. Для переноса на пустое устройство используйте полную резервную копию. Применение финансового файла доступно только из интерфейса и требует действия человека; у помощника нет инструмента записи финансов.

Поля файла и значения `format`/`version` являются контрактом. Будущие изменения должны сохранять чтение v1 или сопровождаться преобразованием версии. Денежные суммы — целые рубли.

## CSV

Кнопка «CSV за период» выгружает журнал внесений и состоявшихся занятий за выбранные даты. В строках есть дата, тип записи, ученик, UUID, получено, начислено и комментарий. CSV разделён точкой с запятой и содержит BOM для удобного открытия в таблицах. Начальные остатки, цены и запланированные занятия в журнал не входят; для полного сохранения финансов используйте JSON или резервную копию.
