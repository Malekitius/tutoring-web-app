# Формат библиотеки задач v2

Библиотека переносится одним файлом UTF-8 JSON. Его структура зафиксирована в [`exercise-library-v2.schema.json`](exercise-library-v2.schema.json). Экспорт и импорт доступны во вкладке «Библиотека». В файле **нет имён учеников, расписания, платежей и загруженных работ**.

```json
{
  "format": "tutoring-web-app.exercise-library",
  "version": 2,
  "exercises": [
    {
      "id": "b7a99146-137b-4f8d-94b4-f4f818cb0bcf",
      "title": "Сложение дробей",
      "prompt": "Вычислите $\\frac{1}{2}+\\frac{1}{3}$.",
      "answer": "Общий знаменатель 6; ответ $\\frac{5}{6}$.",
      "subject": "Математика",
      "grades": [5, 6],
      "topic": "Обыкновенные дроби",
      "subtopic": "Сложение дробей",
      "difficulty": 2
    }
  ]
}
```

## Значение полей

- `id` — постоянный UUID задачи. Для новой задачи создавайте новый UUID. Если импортировать задачу с уже существующим ID, библиотека обновит её метаданные и текст. Ссылки на задачу в готовых подборках сохранятся; содержимое уже добавленной в подборку копии не меняется.
- `subject` — название предмета до 80 символов. Можно добавлять новые предметы без изменения формата файла; одинаковый предмет называйте одинаково во всех задачах.
- `grades` — один или несколько школьных классов от 1 до 11.
- `topic` и `subtopic` — названия темы и подтемы. Пустая строка допустима, если классификация ещё не готова.
- `difficulty` — целое число от 1 (базовая) до 4 (олимпиадная): 2 — средняя, 3 — повышенная.
- `prompt` и `answer` — обычный UTF-8 текст с формулами TeX между `$...$`. При сборке PDF формулы преобразуются локальным XeLaTeX. Не помещайте в эти поля полный документ с преамбулой, команды чтения файлов или произвольные макросы. Для экспорта PDF поддерживается безопасный набор математических команд; неподдерживаемая команда будет показана как ошибка.

Импорт валидирует весь файл до записи. Он добавляет новые задачи, обновляет совпавшие по ID и оставляет остальные задачи библиотеки без изменений. Сначала можно посмотреть предварительный расчёт изменений. Максимум — 10 000 задач и 20 МБ на файл.

**Для кодового агента:** создавайте JSON строго по схеме v2, используйте новые UUID для новых задач, сохраняйте ранее выданные ID при редактуре. Не меняйте `format`, `version` или имена полей без новой версии формата. Экспортированный файл можно импортировать на другом устройстве с этим приложением.

## Совместимость с v1

Импорт старых файлов v1 поддерживается. Уровни 1, 2, 3, 4, 5 переходят соответственно в 1, 2, 2, 3, 3. Прежний уровень 5 обозначал повышенную сложность, поэтому олимпиадный уровень 4 присваивается только явно. Экспорт создаёт файл v2. Схема v1 сохранена в [`exercise-library-v1.schema.json`](exercise-library-v1.schema.json).
