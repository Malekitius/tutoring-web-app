# Локальный кабинет репетитора

Приложение работает на вашем компьютере: Django 5.2, SQLite и собственный веб-интерфейс. Готовы разделы «Ученики», «Расписание», «Задания», «Финансы» и «Данные». Сервер слушает только `127.0.0.1`.

## Быстрая установка на macOS и Windows

Нужен Python 3.11 или новее и интернет для первой установки зависимостей. [Скачайте ZIP актуальной версии](https://github.com/Malekitius/tutoring-web-app/archive/refs/heads/main.zip) и распакуйте его. Для обновления скачайте новый ZIP и повторите те же действия.

- **macOS:** откройте `Install.command`. Если macOS не позволяет открыть скачанный файл двойным щелчком, используйте контекстное меню → «Открыть». После установки запускайте `Start Tutor Cabinet.command` из папки `~/Applications/TutorCabinet`.
- **Windows:** откройте `Install.bat`. После установки запускайте `Start Tutor Cabinet.bat` из `%LOCALAPPDATA%\TutorCabinet\app`.

Установщик создаст отдельное окружение Python, поставит зависимости, обновит структуру базы и создаст файл запуска. Он сохраняет личные данные отдельно от программы: на macOS в `~/Library/Application Support/TutorCabinet`, на Windows в `%LOCALAPPDATA%\TutorCabinet\data`. При первом запуске установщика из прежней папки проекта существующая база, загруженные работы и подключение помощника копируются туда; исходные файлы остаются на месте. При повторной установке существующие данные используются без замены. Перед обновлением остановите работающее приложение. Файл запуска откроет приложение в обычном браузере по адресу [http://127.0.0.1:8765](http://127.0.0.1:8765/).

## Ручной запуск из исходников

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver 127.0.0.1:8765
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765). Остановить сервер можно клавишами `Ctrl+C`. В дальнейшем достаточно последней команды. После обновления кода с новыми моделями данных выполните `migrate` ещё раз.

## Что работает

- Переключение между режимами «Репетиторство» и «Школа». Существующие ученики, занятия, задания и финансы остаются в репетиторстве.
- В школе можно создавать классы с предметом и уровнем, добавлять учеников с датой рождения и комментарием, распределять их по группам «Нужна поддержка», «Осваивает программу» и «Готов к углублению».
- Школьное расписание показывает уроки классов на недельной сетке 09:00–22:00. Доступны разовые и еженедельные уроки, переносы, отмена, отметка проведения и изменение будущей части серии. Время проверяется на пересечения с индивидуальными занятиями.
- Создание, редактирование, поиск и удаление карточек учеников.
- Отдельные цели и уровни по любым школьным предметам, в том числе алгебре, геометрии, физике и химии.
- Темы каждого предмета с четырьмя состояниями освоения и комментариями.
- Общая цель, заметки с приоритетами и дедлайнами, стоимость и длительность занятия.
- Недельный календарь с временной сеткой 09:00–22:00, разовыми и еженедельными занятиями. Высота карточки соответствует длительности урока; свободное время можно выбрать нажатием на сетку.
- Перенос, отмена и отметка «Проведено» для отдельного занятия; изменение будущей части серии.
- Несколько комментариев к занятию: добавление, исправление и удаление, три уровня приоритета или без приоритета, необязательный дедлайн. Комментарии сохраняются при изменении еженедельной серии.
- Комментарии из занятий видны в карточке соответствующего ученика. Там же можно добавлять, исправлять и удалять заметки; изменения связанных заметок отображаются и в расписании. Список упорядочен по приоритету, затем по ближайшему дедлайну; заметки без дедлайна идут по дате создания.
- Быстрые отметки «Состоялось» и «Не состоялось» на карточках занятий. Стоимость проведённого занятия сохраняется на момент отметки.
- Проверка пересечений по времени и перенос карточки занятия на другой день мышью.
- Внесения денег по ученикам, начальный остаток, аванс или долг и подсветка по количеству оплаченных занятий.
- Отчёты по поступлениям за неделю, месяц и произвольный период; отдельно показываются начисления за проведённые уроки и план по расписанию.
- Раздел «Задания» с двумя вкладками: подборки задач «На уроке» и «Домашние». Подборка привязывается к ученику и при желании к занятию.
- Общая библиотека задач с фильтрами по предмету, теме, подтеме, классу и сложности. Задача может подходить нескольким классам. Задача копируется в подборку, поэтому изменение шаблона не меняет уже подготовленные или выданные работы.
- Импорт и экспорт библиотеки одним переносимым JSON-файлом. Актуальный формат v2, примеры и схема для кодовых агентов описаны в [документации](docs/exercise-library-format.md). Файл содержит только задачи, без данных учеников, занятий и платежей.
- Для домашней работы: срок сдачи, статусы, загрузка нескольких фото или PDF с версиями решений, комментарий и отметка проверки либо доработки. Загруженные файлы находятся в `data/uploads/` и не попадают в Git.
- К карточке индивидуального ученика или школьного класса можно прикрепить PDF учебника, задачника или другого материала. PDF открывается прямо в карточке и в форме составления задач, с переходом по страницам. Текст страниц индексируется локально; для сканов текстовый поиск недоступен. В режиме «Из материалов» преподаватель указывает страницы, а помощник переносит задачи в черновик. Подборки класса сохраняются отдельно и экспортируются в PDF.
- Если у перенесённой задачи есть график или рисунок, в черновике нажмите «Добавить из PDF», выберите страницу и обведите нужную область. К задаче можно прикрепить до пяти фрагментов. Рисунки сохраняются вместе с задачей, копируются в подборку и печатаются в PDF. Экспорт библиотеки теперь создаёт ZIP v3 с рисунками; старые библиотеки JSON v1/v2 по-прежнему импортируются. Резервная копия приложения включает рисунки.
- Формулы между `$...$`, например `$\frac{1}{2}$`, отображаются в библиотеке и подборках как математические выражения. В редакторе доступен предпросмотр. KaTeX хранится локально, поэтому просмотр работает без интернета.
- Экспорт каждой подборки в PDF для ученика или PDF с ответами для преподавателя: крупные формулы, отдельные подпункты, рисунки и аккуратные разрывы страниц. Для сборки PDF нужен XeLaTeX с пакетами `babel` (русский язык), `needspace` и `fancyhdr` из стандартной установки TeX Live / MiKTeX.
- Помощник доступен с каждой страницы по плавающей кнопке. Ему можно задать общий вопрос или спросить об учениках; имя и период пишутся прямо в вопросе. Денежные суммы он считает по локальным платежам и проведённым занятиям. Во вкладке «Создать задачи» раздела «Задания» есть два режима: «Создать новые» без PDF и «Из материалов» для переноса задач с указанных страниц. При создании новых задач можно указать отдельное количество для каждой сложности (например, 5 базовых, 2 средние и 1 олимпиадную). Задачи появляются в черновике по одной; если процесс прервётся, готовые задачи останутся и его можно продолжить. Условие и решение можно исправить перед сохранением задач в библиотеку, подборку на урок или домашнюю работу.
- В режиме «Создать новые» можно прикрепить до шести скриншотов PNG/JPEG/WebP выбором файлов, перетаскиванием или вставкой из буфера. Ограничение — 10 МБ на файл и 30 МБ суммарно. По умолчанию помощник переносит исходные задания; в комментарии можно исключить номера либо попросить похожие задачи с другими числами. Скриншоты проверяются и сжимаются локально, не сохраняются в базе и передаются выбранной модели только при генерации. Изображения остаются в текущей форме до удаления или обновления страницы. Передача использует формат [OpenAI image inputs](https://developers.openai.com/api/docs/guides/images-vision).
- После завершения кнопка «Сгенерировать ещё» добавляет задачи в тот же черновик, сохраняя его правки. Количество и сложности для следующей порции берутся из формы; скриншоты и комментарий можно изменить. Максимум в одном черновике — 20 задач. Новая порция получает уже созданные условия, чтобы избегать повторов. «Создать новый черновик» заменяет несохранённые задачи только после подтверждения.
- Раздел «Данные» создаёт полную резервную копию учеников, предметов, тем, расписания, заметок, библиотеки, подборок, работ и финансов. Перед восстановлением показывается состав архива, а прежние данные автоматически сохраняются в локальной папке `data/backups/`.
- В разделе «Финансы» доступны CSV за выбранный период, переносимый JSON со всеми финансовыми записями и загрузка такого JSON с предпросмотром изменений.

Финансовые ответы рассчитываются локально без передачи денежных данных модели. У помощника нет операций изменения платежей, цены занятия, баланса и других финансовых записей. Проверка загруженных ДЗ агентом пока не реализована; проверку выполняет преподаватель.

## Подключение помощника

Откройте помощника по плавающей кнопке на любой странице и нажмите «Подключить ChatGPT». Для подходящего локального приложения OpenAI позволяет использовать лимиты плана ChatGPT через отдельное разрешение. После входа приложение хранит OAuth-токены только в `data/assistant_auth.json` с правами доступа владельца; этот каталог исключён из Git. Вход запускайте через `http://127.0.0.1:8765/`, чтобы адрес обратного вызова и cookie совпадали. Доступность модели зависит от аккаунта и условий OpenAI.

В окне помощника можно выбрать модель из списка, доступного подключённому аккаунту, и уровень Thinking mode. «Авто» оставляет выбор объёма размышления самой модели; более высокие уровни могут расходовать лимит быстрее. Настройка сохраняется локально и действует как для ответов помощника, так и для генерации задач во всех разделах.

Если во время генерации приложение сообщает, что сессия ChatGPT истекла, откройте помощника и нажмите «Подключить ChatGPT» повторно. Приложение сохраняет связь с зарегистрированным клиентом, но удаляет непригодные токены. Ученики, задания, расписание и финансы при повторном входе не меняются.

Если на macOS при входе появляется ошибка проверки защищённого соединения, обновите приложение. Для Python, установленного с python.org, также можно открыть «Программы» → «Python 3.x» → `Install Certificates.command`, затем перезапустить приложение. Не отключайте проверку сертификатов.

Запасной вариант — отдельный API-ключ. Перед запуском сервера установите `TUTOR_ASSISTANT_API_KEY` в окружении. По умолчанию используется модель `gpt-6.1-sol`; её можно сменить переменной `TUTOR_ASSISTANT_MODEL`. Если подключён план ChatGPT, он используется первым. Переменная `TUTOR_ASSISTANT_PROVIDER=openai` принудительно выбирает API-ключ, а `openai_plan` — подключённый план. Ключ и токены не добавляйте в Git.

При общем вопросе модель получает только текст вопроса. Если назван ученик или задан вопрос о группе учеников, ей передаются соответствующие учебные сведения. Денежные поля не включаются в этот контекст; заметки с финансовыми словами скрываются целиком. Вопросы о финансах обрабатываются локально и доступны даже без подключения модели. Период можно задать месяцем и годом, относительным периодом или датами прямо в тексте вопроса; без него используется текущий месяц. Для другого поставщика достаточно реализовать интерфейс `TextProvider` в `assistant/providers.py` и добавить его выбор в `get_provider()` — карточки и библиотеку задач менять не потребуется.

## Как считаются финансы

- «Получено денег» — сумма внесений с датой внутри выбранного периода. Начальный остаток в неё не входит.
- «Начислено» — стоимость занятий со статусом «Состоялось». Цена фиксируется при отметке, поэтому изменение цены ученика не переписывает прошлые уроки.
- «План по расписанию» — начисленное за состоявшиеся занятия плюс стоимость запланированных; несостоявшиеся занятия не входят.
- Баланс ученика за всё время: начальный остаток + внесения − начисления. Если его хватает на 1–2 полных занятия, карточка жёлтая; на 0 занятий или при долге — красная.

## Данные

В разделе «Данные» можно независимо скачать и загрузить архивы репетиторства и школы. Загрузка заменяет только выбранный режим, сохраняя другой режим и общую библиотеку задач. Подборки переносятся вместе с условиями, решениями, рисунками и PDF-материалами; архив репетиторства включает финансы. Для переноса всего приложения используйте полную копию: в неё входит и общая библиотека. Токены подключения к помощнику не экспортируются. Финансовый JSON можно загрузить отдельно в уже существующую базу с теми же ID учеников и занятий; CSV предназначен для просмотра в таблице. Форматы, условия импорта и правила совместимости описаны в [документации](docs/data-portability.md).

По умолчанию база и файлы находятся в `data/`. Переменная окружения `TUTOR_DATA_DIR` позволяет разместить их в другой локальной папке. Для обновления существующей установки оставьте прежнюю папку данных и выполните `.venv/bin/python manage.py migrate`; миграции сохраняют существующие записи. Перед обновлением рекомендуется скачать полную копию через интерфейс.

Приложение пока предназначено для личной работы на одном компьютере; не открывайте его доступ в сеть без настройки авторизации и производственной конфигурации Django.
